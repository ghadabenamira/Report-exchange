# Report Exchange

A student report library built with Flask. Students register, upload their reports as files, search for each other's work, and request access. A report's file stays private until its owner approves the request.

Live demo: https://reportexchange.pythonanywhere.com

## Features

- Two lists, `students` and `reports`, each with POST, GET all, GET by ID, PUT, and DELETE 
- Token authentication: `GET /students` needs a token, `GET /reports` is free
- Access tokens expire after 2 minutes and are renewed with a refresh token (10 minutes)
- Error handling with clear JSON messages and correct status codes
- Report ID is generated by the server
- File upload (PDF, DOC, DOCX, TXT, up to 10 MB) and protected download
- Keyword search by title, type, or keywords
- Access requests: request, approve, or deny
- Student IDs are private: other students only see names
- Profile page and email notifications through FormSubmit
- Modern single-page website served by Flask
- Runs in Docker

## Run with Docker

Requires Docker Desktop.

```bash
docker compose up --build
```

Open http://localhost:5000

Accounts and uploads are saved in a Docker volume (`reportdata`), so they survive restarts.

```bash
docker compose down        # stop, keep the data
docker compose down -v     # stop and delete all data
```

## Run locally without Docker

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # Mac and Linux
pip install -r requirements.txt
flask run --debug
```

Open http://127.0.0.1:5000

## API

Send the token as a header: `Authorization: Bearer <access_token>`

### Authentication

| Method | Endpoint | Token | Description |
|---|---|---|---|
| POST | `/student` | no | Register a student (8-digit `IDs`) |
| POST | `/login` | no | Returns an access token and a refresh token |
| POST | `/refresh` | no | Send `{"refresh_token": "..."}` to get a new access token |

### Students

| Method | Endpoint | Token | Description |
|---|---|---|---|
| GET | `/students` | yes | All students (names, major, level; no IDs, emails or passwords) |
| GET | `/students/<IDs>` | yes | Your own record only |
| PUT | `/students/<IDs>` | yes | Update your own account |
| DELETE | `/students/<IDs>` | yes | Delete your own account and its reports |
| GET | `/me` | yes | Your profile |

### Reports

| Method | Endpoint | Token | Description |
|---|---|---|---|
| POST | `/report` | yes | Upload a report (multipart form: `Title`, `Type`, `K1`, `K2`, `K3`, `Date`, `file`) |
| GET | `/reports` | no | All reports (title, type, owner name) |
| GET | `/reports/<IDr>` | no | One report |
| GET | `/reports/search?q=...` | no | Search by title, type or keyword |
| GET | `/reports/mine` | yes | Your reports |
| PUT | `/reports/<IDr>` | yes | Edit a report (owner only) |
| DELETE | `/reports/<IDr>` | yes | Delete a report (owner only) |
| GET | `/reports/<IDr>/download` | yes | Download the file (owner or approved students) |

### Access requests

| Method | Endpoint | Token | Description |
|---|---|---|---|
| POST | `/reports/<IDr>/request` | yes | Ask the owner for access |
| GET | `/requests/received` | yes | Requests for your reports |
| GET | `/requests/sent` | yes | Requests you sent |
| PUT | `/requests/<IDq>` | yes | Owner answers with `{"Status": "approved"}` or `{"Status": "denied"}` |

### Status codes

| Code | Meaning |
|---|---|
| 200, 201 | Success, created |
| 400 | Invalid or missing data |
| 401 | Missing or expired token |
| 403 | Invalid token, or not allowed |
| 404 | Not found |
| 409 | Already exists |

## Email notifications

The website sends an email through [FormSubmit](https://formsubmit.co) when someone requests access or an owner answers. The first message triggers a one-time activation email to the address set in `NOTIFY_TO` in `templates/index.html`. Confirm it once, and check the spam folder.

## Limitations

- Passwords are stored as plain text (a real app would hash them)
- Tokens are kept in memory, so a server restart signs everyone out
- The server runs one worker, because tokens are not shared between workers
